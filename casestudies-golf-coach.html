Golf Coach

Project Overview

The Golf Coach mobile application is designed to help beginner golfers improve their putting skills using AI-powered camera detection. By analyzing the ball, putter, stance, and hole in real time through a smartphone camera, the app provides instant guidance without requiring expensive coaching sessions or hardware. Beginners often struggle with alignment, rhythm, and distance control, which significantly affect accuracy. This solution offers a convenient way to practice anytime and anywhere. With its AI-based motion analysis and instant feedback system, the Golf Coach app helps users correct mistakes, build confidence, and improve performance consistently through accessible and smart self-training.

Project feature view

A real-time AI-powered putting assistant that detects objects, analyzes stance and stroke motion, and provides instant correction tips through an intuitive interface designed for beginners practicing with only a smartphone.
